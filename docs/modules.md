# Module

## Responsibility
Organizes course content.
`Module` represents a single module.

## Owns
- `Content` objects

## Methods
`add(self, content)`
`remove(self, content)`


# Modules

## Responsibility
`Modules` manages the collection of modules belonging to a classroom.

## Owns
- `Module` objects

## Methods
`create(self, name, description)`
`remove(self, module)`
